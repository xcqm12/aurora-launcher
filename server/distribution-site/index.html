OVERVIEW

它是什么

Aurora Launcher 是一个从零实现的 Minecraft Java 版启动器：不依赖官方启动器，自己完成版本 JSON 合并、库与资源校验下载、 Java 选择、参数组装与进程管理。界面用 React 19 编写，核心逻辑用 Rust 实现，产物是单个 Windows 可执行文件。

🧩 真正的启动，不是壳

  • 递归合并版本 JSON 与父版本，处理 inheritsFrom 继承链
  • 校验并补齐 client jar、libraries、natives、assets objects
  • 按版本要求自动挑选 Java 17 / 21，也可为实例单独指定
  • 失败时报出具体阶段：Java、版本 JSON、下载、natives、参数、进程

⚙️ 加载器一键安装

  • Forge / NeoForge / Fabric / Legacy Fabric / Cleanroom 官方无头安装器
  • OptiFine 版本列表走 BMCLAPI，官网 adloadx 广告页令牌兜底
  • 安装器限时 15 分钟；失败自动补库重试，最多 3 次
  • 库预下载 + SHA-1 校验，走最优镜像候选，弱网也能装完

🛡️ 安全边界写清楚

  • 令牌仅 Rust 侧使用并 DPAPI 加密落盘，不进日志、不给前端
  • 安装器只允许官方白名单域名，下载走 HTTPS
  • 内容管理按实例根目录做路径规范化，拒绝 .. 越界
  • 发布产物剥离符号 + LTO 加固，源码保持 MIT 开源
FEATURES

功能一览

从创建实例、装加载器、找资源，到改配置、联机、看更新日志——日常操作都收在同一处。

📦 实例管理

  • 每个实例独立 mods、saves、config、日志与 game 目录
  • 共享目录仅复用只读的 assets/libraries，省磁盘
  • 实例目录可自定义位置，数据目录可整体迁移
  • 启动版本、内存、Java 路径逐实例配置

🗂️ 实例内容管理

  • 模组：一键/批量启停（重命名 .jar.disabled）、按启用状态排序、搜索
  • 光影包 / 资源包 / 投影原理图：导入、删除、打开目录
  • 存档：解析 level.dat 显示世界名与最后游玩时间，支持备份为 zip 与还原
  • 截图：缩略图墙与大图预览（←/→ 切换、Esc 关闭）
  • 服务器：直接编辑 servers.dat（自动备份，保留最近 3 份）
  • 配置：在线编辑 options.txt 与 config/，Ctrl+S 保存，改动自动备份
  • 以上页面都支持把文件直接拖进面板导入

🔍 资源中心

  • Modrinth 与 CurseForge 双源搜索，按版本与加载器筛选
  • 流式下载 + 实时进度 + SHA-1/SHA-512 校验
  • 整合包 .mrpack / CurseForge zip 导入，实例导出为 .mrpack
  • 模组元数据本地解析（Fabric / Quilt / Forge / NeoForge / mcmod.info），显示真实名称与版本

👤 账户体系

  • 微软正版：设备码登录，内置已过 Mojang 审核的 Client ID，开箱可用
  • LittleSkin：OAuth 设备码授权（推荐）或账号密码，多角色可选
  • 离线账户：OfflinePlayer UUID 算法
  • 启动前自动 refresh，令牌过期提示重新登录

🌐 下载源与镜像

  • 官方 / BMCLAPI / 自动探测（并发测速取更快者，缓存 10 分钟）
  • 自定义镜像源（BMCLAPI 兼容布局），镜像优先、官方兜底
  • 全部流式下载统一重试 3 次，断流不再一次失败
  • 代理可选，留空直连

🤝 EasyTier 联机

  • 房主创建房间 → 房间码分享 → 朋友加入同一个虚拟局域网
  • 虚拟 IP 启动前即确定（房主固定 10.144.144.1，客人从房间码派生），不再等 DHCP
  • 对端在线数实时显示，掉线会计数递减
  • 需要管理员权限创建虚拟网卡；跨网联机需自填共享节点

  • 启动器内置「更新内容」页，随版本附带更新日志，无需联网
  • 日志面板实时推送，进程异常退出时给出排查方向
  • AI 伙伴（实验）：配套 Fabric 模组，游戏内 #ai 对话

GETTING STARTED

使用教程

五步从零到进游戏。首次使用建议按顺序操作。

Aurora Launcher 宣传视频（约 68 秒 · 中文旁白 · 含五步使用教程）

  1. 下载并安装

    选择下方「标准版」安装包（推荐）或便携版。所有产物均带 Authenticode 签名，可对照 SHA256SUMS.txt 复核完整性；便携版解压即用，不写注册表。

  2. 创建游戏实例

    首页「新建实例」→ 选择 Minecraft 版本与加载器（Forge / NeoForge / Fabric / Legacy Fabric / Cleanroom / OptiFine / LiteLoader）。 创建时会自动下载并执行官方安装器，进度条实时显示；装完失败可进入「实例管理 → 设置 → 加载器安装」重试。

  3. 登录账号

    设置 → 账户：微软正版点「微软登录」，按提示在浏览器输入设备码即可（无需任何配置）； LittleSkin 支持 OAuth 授权登录或账号密码；也可以直接添加离线账户。令牌以 DPAPI 加密保存在本机。

  4. 安装资源

    资源中心搜索模组 / 光影 / 材质 / 整合包，选择文件一键安装到当前实例； 也可以在「实例管理」里直接拖入 .jar、.zip、.litematic 等文件导入。 整合包与世界支持自动导入，实例可导出为 .mrpack 分享给朋友。

  5. 启动与联机

    点「启动游戏」自动匹配 Java、选择最优下载源。想和朋友玩：进世界后对局域网开放 → 实例页「联机」卡片创建房间（需以管理员身份运行启动器）→ 把房间码发给朋友 → 朋友「加入房间」后连接你的虚拟 IP。跨网联机请在设置里填写可用的 EasyTier 共享节点。

TROUBLESHOOTING

常见问题

截图或日志能大幅加速定位——日志面板里的内容会给出具体失败阶段。

启动时提示「找不到或无法加载主类 8123」

这是 v0.6.1 的已知缺陷（AI 伙伴的 JVM 参数被拆成两个元素），已在 v0.6.2 修复。请下载当前版本覆盖安装。

Forge 启动即退，日志出现 Modules minecraft and _1._20._1 export package ...

原版 client jar 被错误地放上 classpath 导致的模块冲突，已在 v0.6.5 / v0.6.6 修复。 若仍出现，请确认运行的是新版本（用「关于」里的版本号核对），并重新安装加载器。

创建实例时加载器安装失败 / 提示读取下载内容失败

多为网络抖动或镜像断流。v0.6.3 起所有下载会按地址自动重试 3 次； 也可在设置里切换下载源（官方 / BMCLAPI / 自动 / 自定义镜像），或在实例管理里重试安装。 仍失败可运行仓库里的 scripts/network_check.py 检查各下载端点可达性。

联机卡片显示「虚拟 IP 一直在分配中」

旧版本使用 DHCP，在没有可用共享节点时不会创建虚拟网卡。v0.6.7 起改为启动前确定地址并立即显示， 不再依赖 DHCP。另外请在设置中填写可用的 EasyTier 共享节点——官方公共节点已下线。

联机点「创建房间」失败或提示需要管理员权限

EasyTier 需要创建 TUN 虚拟网卡，必须以管理员身份运行启动器。若提示端口占用， 说明另有 EasyTier 实例在运行，先在任务管理器结束 easytier-core.exe。

微软登录返回 404 / Invalid app registration

内置的 Client ID 已通过 Mojang 审核，正常无需配置。若你在设置里填了自定义 Client ID， 请清空后使用内置值，或确认该应用已加入 Mojang appID 允许列表。

安装包提示「未知发布者」

发布使用自签名证书 CN=SevenZeroMeowTeam：在导入了该证书的机器上显示「有效」， 其他机器会提示未知发布者。可核对 SHA256 与 SHA256SUMS.txt 确认文件未被篡改。

想用自建镜像或代理加速下载

设置 → 下载与目录：可填写代理地址；下载源选择「自定义镜像」并填入镜像站地址（BMCLAPI 兼容布局）。 Aurora 会优先走镜像，失败回退官方源。
